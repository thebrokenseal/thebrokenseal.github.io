ข้อมูลรายละเอียด
บัญชีบัญชีผู้เล่นรับเชิญ (Guest) ผูกกับเครื่อง: รหัสลับสุ่มเก็บในเครื่องคุณ และรหัสแสดงผล (GUEST-XXXX-XXXX) หากคุณผูก Google หรือ Apple เราได้รับรหัสประจำตัวที่บริการนั้นส่งมา เราไม่เก็บโทเคนของเขา
ตัวละครและความคืบหน้าชื่อตัวละคร (2–12 ตัวอักษร) เพศ ทรงผมและสีผม อุปกรณ์ เลเวล สกิล ไอเทม เงิน ความคืบหน้าเควส เก็บบนเซิร์ฟเวอร์เพื่อให้เล่นต่อบนเครื่องอื่นได้
แชตข้อความที่คุณส่งในแชตโลกและแชตแมพ พร้อมผู้ส่ง ห้อง และเวลา แชตมีผู้ดูแลตรวจสอบ
รายงานแชตและบันทึกผู้ดูแลเมื่อมีผู้รายงานข้อความ: ผู้รายงาน ผู้ถูกรายงาน สำเนาข้อความ เหตุผล และผลการดำเนินการ เมื่อผู้ดูแลปิดเสียง เตะ แบน ปลดแบน หรือดูแชตล่าสุด: ใคร ทำกับใคร เมื่อไร และเหตุผลที่เขียนไว้
บันทึกการเล่นและการกันโกงเวลาเข้า/ออกและระยะเวลาที่เล่น แมพและจำนวนผู้เล่นในแมพ การอัปเลเวล จำนวนมอนที่ฆ่า ผลบอสหรือรอยแยก คำสั่งที่เซิร์ฟเวอร์ปฏิเสธ (พร้อมเหตุผล) และเงินที่ได้พร้อมที่มา ใช้ให้เกมยุติธรรมและหาการโกงหรือไอเทมซ้ำ
IP ตอนล็อกอินบันทึกในบันทึกบัญชีพร้อมสิ่งที่เกิดขึ้น (ล็อกอิน ผูก ยกเลิกผูก ผูกไม่สำเร็จ ย้ายบัญชี) เพื่อปกป้องบัญชี
การยอมรับข้อตกลงของคุณเวอร์ชันของข้อตกลง Alpha ที่คุณยอมรับ และเวลา บันทึกบนเซิร์ฟเวอร์
ข้อความที่คุณส่งถึงเรารายงานบั๊กและข้อเสนอแนะที่คุณส่ง และข้อมูลที่คุณให้ตอนสมัครร่วมทดสอบ ใช้เพื่อตอบคุณและแก้ปัญหา

ข. สถิติการเล่น (ปิดได้) เพื่อปรับสมดุลและแก้บั๊ก เราบันทึก สกิลที่ใช้ จุดที่ผู้เล่นตาย เควสที่ทำ ประเภทอุปกรณ์ของคุณ (แพลตฟอร์ม รุ่นเครื่อง ระบบปฏิบัติการ การ์ดจอ หน่วยความจำ ขนาดจอ เวอร์ชันเกม ไม่มีรหัสประจำเครื่อง) ค่าเฉลี่ยเฟรมเรต และรายงานข้อผิดพลาดของเกม (ข้อความ error ที่เกมเจอและตำแหน่งในโค้ด ตัดชื่อโฟลเดอร์ส่วนตัวออก) โดยอาศัยประโยชน์โดยชอบด้วยกฎหมายของเราในการปรับปรุงเกม สถิตินี้ เปิดไว้ให้ทุกคนเป็นค่าตั้งต้น และคุณปิดได้ทุกเมื่อที่ ตั้งค่า → ความเป็นส่วนตัว → "ส่งสถิติการเล่น" เมื่อปิด เซิร์ฟเวอร์จะหยุดบันทึกสถิติของบัญชีคุณ และสถิติที่เคยบันทึกไว้ในชื่อบัญชีคุณจะถูกตัดรหัสบัญชีออก (ไม่มีใครรู้ว่าเป็นของใคร) คุณขออีเมลให้ลบสถิติที่ยังผูกกับบัญชีคุณได้ด้วย การเปิดกลับมาไม่ทำให้แถวเก่าผูกกับคุณอีก

4. ใครได้รับข้อมูลของคุณ

  • SurferCloud โฮสต์เซิร์ฟเวอร์เกมและฐานข้อมูลของเราใน กรุงเทพฯ ประเทศไทย
  • สำเนาสำรองแบบเข้ารหัส อาจเก็บไว้กับ Backblaze B2 ในสหรัฐอเมริกา เข้ารหัสด้วยกุญแจที่มีแต่เราถือ Backblaze จึงอ่านไม่ได้
  • Google และ Apple เฉพาะเมื่อคุณเลือกล็อกอินกับเขา เขาบอกเราว่าคุณคือใคร เราไม่ส่งข้อมูลเกมของคุณให้เขา
  • GitHub (GitHub Pages) โฮสต์เว็บไซต์ของเรา GitHub อาจประมวลผล IP และข้อมูลเบราว์เซอร์ของคุณเมื่อเข้าเว็บ
  • Cloudflare Web Analytics นับจำนวนผู้เข้าชมเว็บไซต์ แบบไม่ใช้คุกกี้และไม่ติดตามคุณข้ามเว็บ
  • ผู้ดูแล: ปัจจุบันมีเฉพาะผู้พัฒนา ซึ่งดูรายงานแชตและแชตล่าสุดเพื่อจัดการรายงาน
  • หน่วยงานรัฐ เฉพาะเมื่อกฎหมายกำหนด

ผู้เล่นคนอื่นเห็นชื่อตัวละคร รูปลักษณ์ เลเวล และข้อความแชตของคุณ แต่ไม่เห็นอีเมลหรือ IP

5. การส่งข้อมูลไปต่างประเทศ

เซิร์ฟเวอร์ของเราอยู่ในประเทศไทย สำเนาสำรองแบบเข้ารหัสอาจไปอยู่ที่สหรัฐอเมริกา และ Google, Apple, GitHub อาจประมวลผลข้อมูลนอกประเทศไทยเมื่อคุณใช้บริการของเขา ประกาศนี้เขียนสำหรับผู้เล่นในประเทศไทย

ตาม PDPA คุณขอให้เรา เข้าถึง และ ขอสำเนา ข้อมูล แก้ไข ลบ หรือทำให้ไม่ระบุตัวตน จำกัด หรือ คัดค้าน การใช้บางอย่าง (สำหรับสถิติ แค่ปิดสวิตช์) ขอรับข้อมูลในรูปแบบที่ โอนย้ายได้ และ ถอน ความยินยอมที่เคยให้ได้

7. ความปลอดภัย

มาตรการของเรา: จำกัดการเข้าถึงเฉพาะผู้พัฒนา แดชบอร์ดสถิติเปิดได้เฉพาะบนเซิร์ฟเวอร์เองผ่านอุโมงค์ที่ปลอดภัย ด้วยบทบาทฐานข้อมูลแบบอ่านอย่างเดียว ไม่เก็บรหัสลับและโทเคนในล็อก ลบ IP ตอนล็อกอินเมื่อครบ 90 วัน ไม่มีระบบใดปลอดภัยสมบูรณ์ หากข้อมูลรั่วไหลจนกระทบสิทธิของคุณ เราจะแจ้งคุณและ สคส. ตามที่กฎหมายกำหนด
